# E-commerce Exploratory Data Analysis (EDA)

## Project Overview
This project focuses on Exploratory Data Analysis (EDA) of an e-commerce dataset using Python. The objective is to explore the data, identify patterns and trends, detect anomalies, and derive meaningful insights related to sales and customer behavior.

## Objectives
- Understand the dataset structure and variables.
- Clean and prepare the data for analysis.
- Analyze sales trends and product performance.
- Explore customer payment preferences.
- Analyze returns, discounts, and shipping.
- Identify patterns, anomalies, and potential data quality issues.

## Dataset Information
- Original records: 2,000
- Features: 23
- Duplicate records removed: 20
- Final records analyzed: 1,980

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn

## Analysis Performed
- Data inspection and cleaning
- Missing value and duplicate analysis
- Descriptive statistics
- Categorical and numerical analysis
- Monthly sales and order trends
- Product category analysis
- Payment method analysis
- Membership analysis
- Return analysis
- Discount analysis
- Shipping analysis
- Outlier detection
- Correlation analysis
- Data quality validation

## Key Insights
- Electronics was the highest-selling product category.
- Books was the lowest-selling product category.
- January recorded the highest sales.
- March recorded the lowest sales.
- Buy Now Pay Later was the most frequently used payment method.
- The return rate was approximately 6.36%.
