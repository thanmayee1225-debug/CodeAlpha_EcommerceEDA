# E-commerce Exploratory Data Analysis (EDA) – Conclusion

## Project Overview
This project explores an e-commerce dataset using Python to understand sales performance, customer purchasing patterns, product categories, payment preferences, returns, discounts, and shipping.

## Dataset
- Original records: 2,000
- Columns: 23
- Duplicate records identified: 20
- Records after removing duplicates: 1,980

## Data Cleaning
- Identified and removed duplicate records.
- Checked for missing values.
- Converted the OrderDate column into datetime format.
- Checked data quality and invalid values.

## Analysis Performed
- Monthly order and sales analysis.
- Product category sales analysis.
- Payment method analysis.
- Membership tier analysis.
- Return analysis.
- Discount analysis.
- Shipping time analysis.
- Weekday versus weekend orders.
- Outlier detection.
- Correlation analysis.

## Key Findings
- Electronics generated the highest sales among product categories.
- Books generated the lowest sales among product categories.
- January recorded the highest monthly sales.
- March recorded the lowest monthly sales.
- Buy Now Pay Later was the most frequently used payment method.
- The dataset contained 126 returned orders, approximately 6.36% of the cleaned records.

## Conclusion
The exploratory data analysis helped identify sales trends, customer purchasing patterns, product performance, payment preferences, returns, and shipping characteristics. The analysis provides useful insights into the dataset and demonstrates how Python can be used to explore data and support data-driven decision-making.
